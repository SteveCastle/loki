Add a worker node

a loki-worker container on a RunPod pod, a cloud VM, or another PC
Start one with docker run --gpus all -p 8080:8080 -e LOKI_WORKER_TOKEN=... -v models:/models ghcr.io/stevecastle/loki-worker, or lokictl pool create runpod-pods.

Add a RunPod serverless endpoint

queue-based; scales from zero, files go through a bucket
Without a bucket, files up to 7 MB go inline (stills work; videos need a bucket). Create one with lokictl pool create runpod-serverless.
