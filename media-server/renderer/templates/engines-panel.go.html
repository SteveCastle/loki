☁️ Worker pools
A pool is a group of interchangeable GPU workers running loki-worker. Each job goes to the least busy healthy worker, preferring one that already has the engine's models loaded.
Start a worker on any machine with an NVIDIA GPU: docker run --gpus all -p 8080:8080 -e LOKI_WORKER_TOKEN=<secret> -v loki-models:/models ghcr.io/stevecastle/loki-worker or let lokictl pool create runpod-pods rent and register pods for you.
Engines and file transfer (needed for videos and files over 7 MB)
Deploy the ghcr.io/stevecastle/loki-worker image as a queue-based endpoint, or run lokictl pool create runpod-serverless. Serverless workers cannot hold interactive sessions: object selection needs a worker node or this machine.
