Conventions

This reference is generated from the server's OpenAPI 3.1 description, openapi.yaml, which you can load into any OpenAPI tool or client generator. Paths are relative to wherever the server is reachable: its host and port, or a reverse proxy in front of it. The port is 10111 unless changed with LOWKEY_PORT or the port config key.

Each endpoint lists its access level, parameters, request body and responses with every field's type. A type name such as Job links to its definition under Schemas. Bodies are JSON unless a content type says otherwise. Booleans in query strings are the literal strings true and false. A path parameter written {id} is one path segment.

Many older handlers do not check the HTTP method and accept any method with the documented body; the method shown is the one the clients send. Where it matters, the endpoint says so.

Code is coloured by role: literal --flag {param} /path ENV_VAR "value" { }

Access Levels

Every endpoint is marked with one of three access levels.

LevelRequirement
PublicNo credential.
ReadA credential, unless the allowPublicAccess setting is on, in which case anonymous requests are accepted. Write methods on a Read path still require a credential while public access is on; the endpoint notes this.
AdminA credential. Every authenticated user is an admin.

A credential is one of: an Authorization: Bearer <token> header carrying a JWT or an lk_ API key; an X-API-Key: <key> header; or the auth_token cookie set by POST /auth/login. Headers are checked before the cookie. JWTs and the cookie are valid for one year; API keys until revoked.

A request that fails authentication receives 401 when it carries a Bearer or X-API-Key header, sends exactly Accept: application/json, or targets a path under /api/. Any other request is redirected with 302: to /setup until first-run setup is complete, then to /login.

While the temporary default admin account is the only user, requests authenticated as it receive 403 with {"error": "setup_required", "message": "Please create a new user account"}; page requests are redirected to /login?setup=true.

Errors

There is no single error envelope. Most handlers write {"error": "<message>"} (the Error schema), often labelled Content-Type: text/plain because they go through Go's http.Error; parse the body as JSON regardless of the header. Older handlers write a bare plain-text message. Each endpoint lists the statuses it returns and which form the body takes. The status codes follow HTTP semantics:

StatusMeaning
400Malformed JSON, a missing required field, an invalid parameter, or a failed validation.
401Missing or invalid credential (see above).
403Path outside every configured storage root, setup required, or a cross-origin form post.
404Unknown job, workflow, model, file, person, or scene.
405Method not supported, on handlers that check the method.
409Conflict: a move destination already in the library, a tag in another category.
413Request body over its cap.
422The input was valid but unusable, for example an image with no face to search by.
500Database or filesystem failure.
503A subsystem is unavailable: the auto scheduler is not running, or the event stream is at its connection limit.

Media Paths

A media item is identified by its path: the absolute filesystem path for local roots, or s3://bucket/key for object storage roots. Paths are compared as stored. Endpoints that serve or process a file refuse paths outside every configured storage root with 403. Paths in query strings must be URL-encoded.

Platform Differences

The Windows, macOS and Linux servers register the same routes with the same access levels, with these exceptions:

  • POST /api/embedding/directml/install and the /events page exist only on Windows.
  • The /stats page exists only on macOS and Linux.
  • GET /tasks includes each task's options only on Windows.
  • POST /api/upload honours the destination field only on Windows; macOS and Linux always write to uploads/ in the default root.
  • /api/scene-dream endpoints exist only in builds made with the Dream feature (LOKI_DREAM=1).
